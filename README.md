## Windows 安裝

下載 [最新版本 MSI 安裝檔](https://github.com/funny4875/DocPilot/releases/latest)，執行後可從開始功能表或桌面啟動。安裝版內含 Python 執行環境，仍需安裝 Google Chrome。帳密、腳本與截圖存於 `%LOCALAPPDATA%\DocPilot`；解除安裝不會刪除這些使用者資料。既有來源碼版本資料不會自動移轉。

## 從原始碼啟動

雙擊 `啟動多帳號登入.bat`，新增帳號與密碼，或從下拉選單選擇已儲存的帳號，再按「登入」。登入成功後 Chrome 會保持開啟，關閉介面時會關閉 Chrome。

帳密以 Windows DPAPI 加密保存在 `accounts.dpapi`，只有目前的 Windows 使用者可解密。首次啟動會匯入舊的 `temp.txt` 與 `temp - 複製.txt`；確認加密檔可讀後刪除這兩個明文檔。若兩檔有相同帳號但不同密碼，會停止匯入並保留明文檔，供人工核對。

登入曾經實際驗證；新增的公文操作與腳本功能仍需在正式網站確認。電腦需有 Chrome，以及含 Selenium、ddddocr、pywin32 的 Python；啟動器優先使用資料夾內 `.venv`，其次使用 Thonny Python。

## 公文操作與腳本

選擇其他已儲存帳號並按「登入」時，程式會先關閉目前由本程式開啟的 Chrome，再開啟新的登入工作階段；切換後「已輸入 PIN」狀態會重設。

登入後可點選主辦、會辦清單與目前清單的第一列。Chrome 啟動時自動最大化，主視窗位於螢幕右上角。「已輸入 PIN」核取方塊是本次程式工作階段的共用狀態，可手動勾選或取消。公告週知、送歸存檔與自動會辦執行時，若未勾選，第一輪使用對應的 `_要輸入pin.script`；該腳本成功完成後自動勾選，後續輪次及這三個流程再次執行時使用不含 `_要輸入pin` 的腳本。取消勾選後，下次會再次執行 PIN 版本。執行前會先檢查本次所需腳本；腳本須自行包含每輪返回清單、開啟下一則的步驟。尚未建立流程時，請先在編輯器錄製或編寫並儲存。

「腳本編輯／錄製」可載入、編輯、儲存、執行一次，或開始錄製後到登入的 Chrome 操作，再按停止錄製。步驟會附加在編輯器內容末尾，請檢查、修正後儲存。錄製依賴網頁事件，切換分頁、iframe、彈出視窗、網站內建對話框及快速跳頁未必能完整記錄；錄製後須核對。網站的 PIN 若不是密碼欄位，可能被記錄為明文，請儲存前自行改成 `${PIN}`。密碼類欄位自動記錄為 `${PIN}`，執行時提示輸入，並不寫入腳本。

每行一個 JSON 物件，空行及 `#` 開頭註解會略過：

```text
{"action":"click","xpath":"//*[@id='button']"}
{"action":"clear","xpath":"//*[@id='field']"}
{"action":"paste","xpath":"//*[@id='field']","value":"公告網路週知。"}
{"action":"send_keys","xpath":"//*[@id='field']","value":"文字"}
{"action":"send_keys","xpath":"//*[@id='pin']","value":"${PIN}"}
{"action":"key","xpath":"//*[@id='field']","value":"ENTER"}
```

`key` 支援 `ENTER`、`TAB`、`ESCAPE`。找不到可操作的 XPath 時最多等待 5 秒，然後停止並顯示第幾輪與行號。腳本可能包含正式送出或簽章動作，執行前請先檢查內容及目前公文。

錄製時在 Chrome 按 Ctrl+V，會把當時貼上的純文字記成 `paste`；執行時會以腳本文字取代剪貼簿原有內容（包括圖片），再執行貼上；原有內容不會還原。若使用 `${PIN}`，PIN 也會留在剪貼簿，使用後請複製其他內容取代。錄製貼上含敏感資料時，請檢查腳本；密碼欄位使用 `${PIN}`。若欄位中的游標位置或選取範圍影響貼上結果，請檢查錄製結果並實際測試。

錄製中的動作會逐步顯示在文字框。點選某一行，在「所選步驟名稱」輸入說明後按「設定名稱」，即可將名稱存入該步驟的 `name` 欄位；名稱不影響執行，錯誤提示會顯示名稱。錄製完成後仍須按「儲存」。

腳本編輯器左側顯示行號；捲動與修改內容時會更新。錄製時按「暫停錄製」，待狀態顯示已暫停後的 Chrome 操作不會記錄；按「繼續錄製」恢復，按「停止錄製」結束。登入、執行或錄製期間，互相衝突的按鈕會暫時停用。


腳本可插入等待步驟（每行一個 JSON）：

```text
{"name":"等待 3 秒","action":"wait","seconds":3}
{"name":"等待公文清單","action":"wait_for","xpath":"//*[@id='dg']/tbody/tr[1]","timeout":30}
{"name":"開啟公文","action":"click","xpath":"//*[@id='example']","timeout":30}
```

`wait` 固定等待指定秒數；`wait_for` 等待元素可見且可操作，未設定 `timeout` 預設 5 秒。每個 XPath 動作（例如 `click`）執行前都會等待目標可見且可操作，出現後立即執行；每步可各自設定 `timeout`，錄製步驟預設帶入 5 秒。逾時會停止並顯示步驟名稱。名稱欄位顯示在最前方。`_要輸入pin` 腳本若使用 `${PIN}`，執行時會要求輸入 PIN；不會自動產生任何簽核步驟。

腳本編輯器可用「新增腳本」建立自訂名稱，並從下拉選單選取、編輯及執行；選取時會自動載入。可用「刪除腳本」刪除自訂腳本，六個固有流程名稱不可刪除。切換、重新載入或關閉時，若有未儲存的內容會先提示。自訂腳本可在編輯器手動執行，不會自動加入主畫面的流程按鈕。
